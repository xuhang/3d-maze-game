# 雾锁迷宫 / FOGBOUND MAZE

一个可直接在浏览器打开的第一人称 3D 迷宫逃生游戏。整款游戏打包在单个 `index.html` 中（Three.js r149 已内联），不依赖任何外部图片、音频或 CDN，断网也能完整运行。

## 玩法

1. 在开始界面选择难度，进入随机生成的迷宫。
2. 在迷宫中收集全部钥匙，出口封印门会由深红变为青绿高亮并解锁。
3. 走进解锁后的出口即通关，结算界面显示通关用时、步数、难度与钥匙数。
4. 顶部 HUD 显示计时、步数、钥匙进度与当前目标，右上角小地图显示迷宫全貌、钥匙位置、出口与朝向。

| 难度 | 迷宫尺寸 | 钥匙数量 |
| --- | --- | --- |
| 简单 | 11 × 11 | 3 |
| 普通 | 15 × 15 | 5 |
| 困难 | 21 × 21 | 7 |

## 操作

### 桌面端

| 操作 | 按键 |
| --- | --- |
| 移动 | `W` `A` `S` `D` 或方向键 |
| 转向 | 鼠标（点击画面后会锁定指针） |
| 冲刺 | 按住 `Shift` |
| 暂停 / 继续 | `Esc` |

### 移动端 / 触屏

- 左下角虚拟摇杆：移动
- 屏幕右侧滑动：转向
- 按住右下角「冲刺」按钮：加速
- 右上角按钮：暂停

## 语言 / Languages

支持简体中文、繁體中文、English、日本語。首次打开会按浏览器语言自动选择，匹配不到时回退到英文；开始界面右上角可手动切换，选择会保存在本地，下次打开自动沿用。

所有文案集中在 `index.html` 内的 `I18N` 字典中。新增语言只需复制一个字典条目、填写 `htmlLang`、`nativeName`、`match` 以及 `strings` 翻译，无需改动界面或游戏逻辑。

在线试玩：https://xuhang.github.io/3d-maze-game/

## 本地打开

方式一：直接双击 `index.html`，用 Chrome / Edge / Firefox / Safari 打开即可（无需服务器）。

方式二：起一个本地静态服务器：

```bash
python3 -m http.server 8080
# 然后访问 http://127.0.0.1:8080/index.html
```

## 实现概要

- 程序化迷宫：DFS 回溯生成，再按难度随机打通少量隔墙形成环路；BFS 选取离出生点最远的空格作为出口。
- 渲染：墙体使用 `InstancedMesh` 合批；砖墙、石板地面、天花板、光晕、传送门、浮尘全部由 Canvas 生成纹理。
- 氛围：指数雾、环境光/半球光、随身手电（SpotLight）、出口点光源。
- 移动：带加速度阻尼的第一人称移动，`delta time` 更新保证帧率无关；圆形玩家碰撞体与墙体分轴 AABB 检测，避免穿墙。
- 交互与反馈：钥匙拾取、出口解锁、锁门提示与通关音效均由 Web Audio 程序合成。
- 其它：指针锁定、触屏降级控制、窗口自适应、暂停遮罩、开局说明与结算界面、小地图。
